# Namey — marketing launch plan

**Owner:** Mr Marketing  
**For:** Berry (Namey lead)  
**Date:** 2026-09-11  
**Scope:** Namey only. Quiet until live. Profit ASAP without burning trust or ad spend on a tunnel URL.

**Hard gates before any paid traffic or “go big” posting**
- Permanent public URL (not Cloudflare quick tunnel)
- Share caption includes that stable URL
- Share card + A2HS smoke-pass on iOS Safari + Home Screen

Until then: seed content, rehearse scripts, collect waitlist emails on a one-pager if needed — **do not** point TikTok bios at a rotating tunnel.

## 1) TikTok + organic launch

### Positioning (one line)
**Not another baby-name list — the fun way you actually decide.** Short quiz → endless deck → share the name + hidden meaning.

### Audience
- Primary: UK expectant parents in the shortlist phase (trying for / pregnant / newly pregnant)
- Secondary: partners + grandparents helping shortlist
- Feed language: en-GB, plain, never cutesy

### Creative system (what we post)
Every post is built around the **ShareCard** (blue/pink, name + motif + meaning). The card *is* the ad. Screenshot path this week (no image-file share required).

| Asset | Spec |
| --- | --- |
| On-screen visual | 9:16 ShareCard (or live screen record of deck) |
| Caption | Name + meaning + soft CTA (see templates) |
| Sound | Trending soft / emotional OR original voiceover |
| Length | 7–20s for hooks; 20–35s for story scripts |
| Face | Optional. Faceless card + VO works for volume |

### Hooks that stop the scroll
1. “We both liked the same name and didn’t know what it meant.”
2. “This name means ___ and I can’t stop saying it.”
3. “Skip the 500-name PDF. Quiz → shortlist in minutes.”
4. “POV: your shortlist finally fits on one screen.”
5. “Hidden meaning behind [Name] that made us cry (a bit).”

### Caption templates
Use Writer’s product captions for in-app share; these are **TikTok post** captions.

**A — Meaning reveal**
```
{Name} — {hidden meaning}

Found it on Namey (quiz → shortlist, stays on your phone).
#babynames #namey #pregnant
```

**B — Couple / decision**
```
We were stuck. Three-minute quiz later… {Name}.

If you’re shortlisting, try Namey — no account, shortlist on this phone.
```

**C — Soft CTA / waitlist**
```
{Name} hit different.

Link in bio when we’re live · Namey Pro waitlist open for partner shortlists.
```

**D — Faceless volume**
```
Name + meaning. That’s the post.

Namey — find your baby’s name without the spreadsheet.
```

### Posting cadence (first 14 days after stable URL)

| Window | Cadence | Mix |
| --- | --- | --- |
| Soft launch (days 1–3) | 2/day | 1 meaning-reveal · 1 deck/screen-record |
| Ramp (days 4–10) | 2–3/day | 60% meaning cards · 20% “how it works” · 20% UGC-style / duet bait |
| Steady (day 11+) | 1–2/day | Double down on whatever gets saves + profile visits |

**Account hygiene**
- Bio: one line + **stable** link (or Linktree → app + Pro waitlist)
- Pin best meaning-reveal + one “how Namey works” 
- Reply to every parent comment in-voice for first 2 weeks (growth > polish)
- Duet/stitch name discourse only when we can land on a ShareCard in-frame

**Do not** run Spark Ads / boost until: stable URL + 3 creatives with organic saves above your baseline.

## 2) Funnel: free quiz → save → share → paid upsell

```
TikTok / Reels / word of mouth
        ↓
   Land on Namey (stable URL)
        ↓
   Gender → filters → quiz (“Not sure” ok)
        ↓
   Endless deck (see ≥10 names before popups)
        ↓
   Save ♥  →  shortlist on device
        ↓
   Share card / caption  →  partner or feed  →  new quiz starts
        ↓
   A2HS (“Keep Namey handy”) after save + enough names seen
        ↓
   Paid upsell moment (see §3)
```

### Stage jobs

| Stage | Job | Metric |
| --- | --- | --- |
| Hook | Stop scroll with name + meaning | 3s hold, watch % |
| Activate | Finish quiz → first deck swipe | Quiz complete rate |
| Value | First save | ≥1 favourite |
| Spread | Share (card screenshot or caption) | Share attempts / session |
| Retain | A2HS / return visit | Install or D1 return |
| Monetise | Tip / Pro waitlist / affiliate tap | £ or email captured |

### Guardrails (trust = the brand)
- Trust strip stays true: **on this phone · no account**
- No dark patterns; upsell only **after** a save or share (value first)
- Never put a rotating tunnel in captions or bio

### Loop we optimise for
**Share → new parent opens → quiz → save → share again.**  
Partner “both liked” is P1 after share works (Product); until then, captions do the couple story.

## 3) First revenue bet

### Decision: **Namey Pro waitlist (primary) + tip after share (cash this week)**

| Option | Verdict | Why |
| --- | --- | --- |
| **Paid ads first** | No | Burning £ into a tunnel / unproven creative. Unlock after stable host + organic winners. |
| **Tip jar** | **Yes — ship first for cash** | Privacy-safe, one-screen, after share/save. Small ARPU but real £ while quiet-pre-launch. |
| **Namey Pro waitlist** | **Yes — primary bet** | Highest LTV path. Sell *partner shortlist / sync later* without breaking today’s on-device story. Captures emails for launch day. |
| **Affiliate** | Later | Nursery/print affiliates fit the moment but risk “sponsored names” vibes. Revisit after Pro waitlist + tip are live. |

### Why this mix
1. **Edward wants profit ASAP** → tip jar can ship in days and collect £ without ad spend.  
2. **Brand & roadmap** → Pro waitlist funds the real product (partner / sync) and builds a list for launch noise.  
3. **Trust strip** → tips and waitlist don’t need tracking pixels or accounts inside the quiz.  
4. **Ads** → only when the URL won’t die mid-campaign.

### Pro waitlist offer (draft)
> **Namey Pro (coming)** — share one shortlist with your partner, keep favourites if you change phones.  
> Join the waitlist · free while we’re early.

Price signal later with Product (don’t invent £ here). Waitlist CTA after first share or from Favourites.

### Tip moment (draft)
After a successful share: soft sheet — “Namey’s free. Tip the build if you like?” · Skip always easy.

### Explicit non-goals this week
- In-app display ads  
- Buying TikTok traffic  
- Fake “nationwide” or store listing until A2HS + trust copy are solid

## 4) Five TikTok scripts parents will actually watch

Keep on-screen text huge. Cut dead air. End on the ShareCard freeze-frame.

### Script 1 — Meaning gut-punch (7–12s)
**Visual:** Black → ShareCard slides up.  
**VO / text:** “We almost skipped this one.”  
**Beat:** Reveal `{Name}` → “It means {hidden meaning}.”  
**End:** “Found on Namey.” Soft smile / silence.  
**Caption:** Template A.

### Script 2 — Spreadsheet hate (15–20s)
**Visual:** Ugly Notes app list → swipe to Namey quiz → deck.  
**VO:** “If your baby-name notes look like this… stop.”  
**Beat:** Three taps through quiz → first save.  
**End:** ShareCard of the saved name.  
**CTA:** “Quiz → shortlist. On your phone.”

### Script 3 — Partner POV (20–30s)
**Visual:** Split: two phones / two thumbs on deck (or one phone, “send this to them”).  
**VO:** “You’re not picking a name. You’re picking one you’ll both still like at 3am.”  
**Beat:** Save → share sheet → ShareCard.  
**End:** “Namey — decide together without the argument spreadsheet.”  
**Note:** Lean into couple story even before partner accounts ship.

### Script 4 — One-name deep dive (12–18s)
**Visual:** Screen-record Name detail: motif, meaning, similar names (when shipped).  
**VO:** Whisper energy — “Okay but the meaning though…”  
**Beat:** Hold on hidden meaning 2 full seconds.  
**End:** Share gesture.  
**Hashtags:** name-specific + #babynames.

### Script 5 — “Not sure” permission (15–25s)
**Visual:** Parent stuck on a quiz question → taps **Not sure** → still gets a deck.  
**VO:** “You don’t need a Pinterest personality to get a shortlist.”  
**Beat:** Skip pressure → first ♥ → A2HS hint only if it fits naturally (don’t force popup in creative).  
**End:** Trust line on screen: “Shortlist stays on this phone · no account.”
