## Order of operations

1. Create developer account (~USD 25)
2. Create app **Namey**
3. Privacy URL + Data safety (favourites on-device; optional waitlist email; no sale of data)
4. Content rating (parents / general — not Designed for Families)
5. Store listing + assets
6. Upload AAB → **Internal testing** first
7. After upload: copy **App signing** SHA256 → send to Berry to update assetlinks
8. Smoke install → then Production **Publish** when happy
